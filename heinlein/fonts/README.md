# Bundled PDF fonts

Reproducible PDF builds load these local TrueType files rather than fetching
fonts from Google at render time.

- Inter v20: `Inter-*.ttf` — SIL Open Font License, `OFL-Inter.txt`
- Lora v37: `Lora-*.ttf` — SIL Open Font License, `OFL-Lora.txt`
- JetBrains Mono v24: `JetBrainsMono-*.ttf` — SIL Open Font License,
  `OFL-JetBrainsMono.txt`

The assets are the same family/weight/style set previously requested through
the Google Fonts stylesheet in `print.html.j2`.
