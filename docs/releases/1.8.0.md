# Heinlein Studio 1.8.0

Custom review agents, chapter editing and project conversations are brought
together in one local app build. Review suggestions now offer Previous and Next
controls and advance after a decision while retaining the existing confirmation
and manuscript-safety checks.

Scene actions can insert a scene above or below the selected scene, keeping the
manuscript and Library order together. Menu targets retain their physical minimum
size at reduced and enlarged text sizes.

Saved ChatGPT connections restore securely after restart. Interrupted reviews can
resume failed or interrupted chunks while retaining successful results; changed
source requires a fresh capture. The MCP connection command now has its explicit
native permission declaration, retaining project consent and source protections.

This build also includes the existing Markdown Reading, daily progress, durable
preferences and five-format manuscript export features from 1.7.3. The independent
Python publisher remains at 0.1.0.

This is a local Apple Silicon build with the stable application identifier
`me.thearcades.heinlein.studio`. No public release or tag is created by this
packaging work. Automated and installed-app verification is recorded separately
in the local assembly evidence; live-provider and VoiceOver acceptance must not
be inferred from synthetic tests.
