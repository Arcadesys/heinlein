# Heinlein Studio 1.7.2

Export a Library group, project, or source folder as one Markdown file for beta readers. Nested content and reference sheets are included. Exports follow Library reading order where available, use current editor text, add headings, and omit YAML metadata. Images and attachments are not bundled. The native Save dialog creates a new file outside the source project; source files are preserved.

Define reusable review agents in **More actions → Review agents…**, or from the review panel. Start from a template or describe what to look for in plain language. Choose notes only or notes with suggested edits. Agents are available across projects; each review still sends only the text the author selects, and changes remain advisory until approved.

This release also includes the recent review-feedback, background-progress, reference-sheet, Library-dragging, sidebar-position, and release-update improvements already merged into main. Existing installations can use **Heinlein Studio → Check for Updates…** to find published releases. Downloaded updates are installed manually after saving and quitting.

## Downloads

The ZIP and DMG contain the same self-contained **Heinlein Studio.app** for Apple Silicon Macs. Verify the download against `SHA256SUMS`. Quit Heinlein Studio, expand the ZIP or open the DMG, and copy the app to Applications.

The stable application identifier and profile are preserved. App downloads contain no manuscripts, credentials, account data, or source-update launcher. Existing managed source installations retain their separate updater.

The app is ad-hoc signed, without Developer ID signing or notarization. The declared minimum is macOS 11; older macOS runtime compatibility is unverified. Intel, Windows, and Linux installers are not included. The Python publisher remains at version 0.1.0 and is unchanged.

Build command: `OPENSSL_STATIC=1 npm run tauri build -- --config src-tauri/tauri.release.conf.json --bundles app --ci`.

The release manifest records source identity, artifact hashes, verification results, and remaining limitations.
