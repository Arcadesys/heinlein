# Heinlein Studio 1.10.0

Full screen now opens to the manuscript with application controls and editor panels hidden. Use **Hide controls** in a window, or Command/Ctrl+Shift+H, to slide the controls away. The same shortcut restores them. Moving to the top edge reveals **Show controls**, which is also reachable with Tab. Escape exits full screen. An optional daily word goal is available under **Appearance → Editor**; it is off by default. Save failures and recovery dialogs reveal the controls again.

The document toolbar has one labeled **Close** control per tab and groups secondary tools under **Document actions**. Source, Reading and Heinlein remain direct actions. Text stays large, keyboard focus stays distinct, and hiding the controls preserves manuscript width and wrapping within the current view.

New projects create a separate local folder and an empty **First scene**, then open that scene for writing. Existing writing is never overwritten. Typewriter choices include Classic mechanical and the four kept Sound Sketchbook sounds, with remembered volume up to **500%**. Existing volume settings are retained.

This release also includes the current main-branch improvements for review recovery and same-account reauthentication, standalone-draft review, group and manuscript word counts, the Editors drawer, and guarded project-level MCP access. Review advice remains advisory; manuscript changes still require the author's explicit decision. The release updater can build a selected published version from its tag when the required local build tools are available.

## Downloads and updates

The Apple Silicon ZIP and DMG contain the same self-contained **Heinlein Studio.app**. Verify downloads against `SHA256SUMS`. Save and quit Heinlein before copying the app to Applications. Existing source-managed installations retain their own update path.

The stable `v1.10.0` tag and published GitHub release include the DMG name required by the release updater: `Heinlein-Studio-1.10.0-macos-arm64.dmg`. A tag without a published release and its DMG is insufficient for update discovery.

The app uses the existing stable application identifier. Downloads include no manuscripts or account data. The app is ad-hoc signed and is not Developer ID signed or notarized. The declared minimum is macOS 11; older-macOS runtime compatibility, native VoiceOver acceptance and live-provider recovery are not established by the automated checks. Intel, Windows and Linux installers are not included. The independent Python publisher version remains 0.1.0.

The release manifest records source identity, artifact hashes and verification evidence.
