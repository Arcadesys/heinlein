# Heinlein Studio 1.7.3

Daily word-goal progress stays visible in the writing header without moving the
manuscript as counts change. Standalone drafts now offer Source and Reading views
with formatted Markdown, preserving the current text, selection and undo history.

Appearance, fonts, zoom, navigation, custom themes, daily progress and sound choices
are saved in a versioned native preferences file outside the application bundle.
The first launch conservatively imports allowlisted choices from the current
WebKit profile. Existing native values win; original migration payloads and a
previous-file backup are retained. Conflicting revisions, unreadable settings and
write failures are reported instead of silently replacing saved choices.
Keep the stable production application identifier when updating. Development and
preview profiles remain separate; manuscripts and credentials are not migrated.

Choose **Export manuscript…** in the Library header, at the top of Project actions,
or in the command palette. One dialog supports Markdown, PDF, EPUB, HTML and DOCX,
with an optional author byline and reference sheets excluded by default. Exports
preserve manuscript order and use the current writing buffer. Group and folder
actions show their selected scope. The Save dialog creates a new file outside the
source project and refuses to overwrite existing files. Images and attachments
are not bundled.

Markdown needs no converter. Other formats require a local Python 3.11+ runtime
with Heinlein dependencies and Pandoc; PDF also requires Chrome or Chromium.
The app bundles the publishing adapter and plain manuscript templates, not these
external runtimes. Missing dependencies produce a retryable error. The independent
Python package version remains 0.1.0.

This source version does not itself publish downloadable releases or update an
installed app. The existing release build remains Apple Silicon, ad-hoc signed
and unnotarized; other platforms and older macOS runtime compatibility are not
established by this change. Native installed-app, OS-picker, VoiceOver and
existing-user upgrade acceptance remain separate from automated verification.
