# Heinlein Studio 1.11.0

Book design is now editable in the app. The publishing step of the **First story** guide has **Book design** controls for style, page size, large print, body and display fonts, cover, title page, copyright page, subtitle and dedication. Studio defaults to the new unbranded **Plain** style. The same settings live in `heinlein.yaml` (`imprint: plain`, `fonts`, `front_matter`, and the `small` and `a5` page sizes), so the command-line build follows what the author chose. An unknown imprint name is now an error instead of a silent fallback. The command-line default remains FREE PLAY.

Claude can now be chosen as the model for Ask, Revise and Review, next to ChatGPT. The Anthropic API key is kept in the macOS Keychain. Studio can also connect Claude Code and Claude Desktop to a Heinlein project.

Writing and review improvements:

- **Author notes** let the author leave notes in the manuscript that steer model edits.
- Review suggestions float beside the highlighted text they refer to.
- **Expand all** and **Collapse all** in the chapters and scenes navigation.
- **Open source folder in Finder**, from Project actions or the command palette.
- **Run review** now continues through every batch instead of stopping early, and a set of alternative rewrites counts as one suggestion.

Review advice remains advisory; manuscript changes still require the author's explicit decision.

## Downloads and updates

The stable `v1.11.0` tag and published GitHub release must include the DMG name required by the release updater: `Heinlein-Studio-1.11.0-macos-arm64.dmg`. A tag without a published release and its DMG is insufficient for update discovery.

Download, signing and platform notes are unchanged from 1.10.0. The independent Python publisher version remains 0.1.0.
