# Heinlein Studio 1.5.0 — release draft

Status: unreleased. No tag, GitHub release, signed installer, or live MCP client
configuration has been created. Integrated local checks passed; native smoke testing remains a release gate.

## Writing milestone

- Local Markdown drafting with explicit save, undo/redo/find, adjustable type and
  high-contrast presentation
- Idle/continuous-typing autosave with private durable recovery snapshots,
  explicit recovery choices, and external-change protection
- An explicitly created ms/ manuscript: stable scene identity, reading order,
  optional groups, imports, moves, keyboard arrangement and guarded undo
- Optional typewriter sounds, scene/manuscript counts and adjustable daily writing
  targets, with conservative local growth credit
- Local MCP-assisted drafting uses read/propose-only tools and explicit Studio
  review/apply with guarded revert and attributed receipts; direct agent saves and persistent grants are deferred

## Existing manuscripts

Legacy schema-v1 projects continue to open. Copy legacy scenes explicitly to
create an independent ms manuscript. Copies are not synchronized and the old
project remains unchanged. Nothing is migrated merely by opening a repository.

## Boundaries to state in the release

- Recovery is the latest snapshot per scene, not a complete revision-history UI
- Recent typing before durable staging can be lost on forced termination
- Asset migration and directory-tree imports are deferred; recognized relative
  asset-bearing directory transfers are blocked
- Local daily goals may undercount rewrites/complex edits and do not synchronize
- Manuscript export/publication is deferred for this drafting milestone
- MCP client connection requires separate local setup and user approval; this
  patch does not configure credentials or install persistent access
- Native build/runtime, OS dialogs/drop, accessibility and physical interaction
  must be verified separately; mocked tests do not establish those outcomes
